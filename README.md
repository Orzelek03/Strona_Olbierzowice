⛪ System Zarządzania Parafią (Laravel & React Inertia)
Nowoczesna aplikacja webowa stworzona na potrzeby parafii, łącząca publiczny portal informacyjny z zaawansowanym, zabezpieczonym panelem administracyjnym. Projekt opiera się na architekturze SPA (Single Page Application) z wykorzystaniem biblioteki Inertia.js.

🚀 Główne Funkcje
Portal Informacyjny (Strona Publiczna):

Strona główna z aktualnościami i dynamicznym ładowaniem treści.

Sekcja aktualności/postów z powiązanymi galeriami zdjęć.

Ogłoszenia duszpasterskie (z podziałem na lokalizacje, np. Olbierzowice, Nawodzice) oraz katechezy parafialne.

Harmonogram intencji mszalnych z sortowaniem po dacie i godzinie.

Interaktywna galeria zdjęć z widokiem albumów.

Historia parafii oraz zakładka kontaktowa.

Panel Administracyjny (/admin):

Chroniony system autoryzacji z dedykowanym przekierowaniem dla administratorów.

Intuicyjny pulpit zarządzania (Dashboard) z kafelkami szybkiego dostępu.

Pełne zarządzanie CRUD dla: Albumów, Postów, Intencji oraz Ogłoszeń.

Automatyczne, skalowalne zarządzanie plikami (każdy album tworzy swój unikalny podfolder na serwerze, co zapobiega konfliktom nazw i ułatwia czyszczenie danych).

🛠️ Technologie
Projekt został zbudowany przy użyciu następującego stosu technologicznego:

Backend: PHP 8.2+, Laravel Framework

Frontend: React, TypeScript, Inertia.js

Stylowanie: Tailwind CSS, CSS / SCSS

Baza danych: MySQL

Środowisko uruchomieniowe: Docker & Laravel Sail

Zarządzanie plikami: Laravel Storage (symlinki publiczne)

⛪ Parish Management System (Laravel & React Inertia)
A modern web application built for a local parish, combining a public information portal with a secure, feature-rich administrative dashboard. The project is built using a Single Page Application (SPA) architecture powered by Inertia.js.

🚀 Key Features
Public Portal:

Homepage featuring latest news and dynamic content loading.

News and posts section with attached photo galleries.

Parish announcements (categorized by locations, e.g., Olbierzowice, Nawodzice) and catechesis sessions.

Mass intentions schedule sorted by date and time.

Interactive photo gallery with album views.

Parish history and contact page.

Administrative Panel (/admin):

Protected authentication system with customized redirection for administrators.

Intuitive dashboard with quick-access cards.

Full CRUD management for: Albums, Posts, Intentions, and Announcements.

Automated, scalable file storage (each album creates a unique subfolder on the server to prevent naming conflicts and ease data cleanup).

🛠️ Technology Stack
Backend: PHP 8.2+, Laravel Framework

Frontend: React, TypeScript, Inertia.js

Styling: Tailwind CSS, CSS / SCSS

Database: MySQL

Environment: Docker & Laravel Sail

File Management: Laravel Storage (public symlinks)
